青鬼AR

v0.19.3 (build 35) · HUD を画面内に収める
インストール
  • Safari で開くこと。他のブラウザでは動きません
  • 登録済みの iPhone にのみインストールできます
  • iOS 18.0 以降
  • 初回は「設定 → 一般 → VPN とデバイス管理」で開発元を信頼
  • 体を指でなぞると引きずれます。重みがあって指に遅れて付いてきます
  • 2本指で上下すると持ち上がります。離すと落ちます
  • 「メッシュ」ボタンで部屋の形が見えます。机や壁に本当にぶつかります
  • 青いボタンで 青鬼 / 羊 を切り替え、ピンクで 3D / 2D を切り替えられます
  • 2Dは回り込むと正面/横/後ろが切り替わります
  • 掴む・落とす・撫でるで表情が変わります
  • 水色ボタンで深度の取得元: LiDAR / 人物推定 / ZipDepth / DepthAny / Niantic
  • CoreML は相対深度なので、LiDAR 機で数秒使うと縮尺が自動較正され保存されます
  • Niantic を使うには、Files アプリで AoOniAR の書類フォルダに niantic_token.txt(開発者トークン)を置いてアプリを再起動
  • 黄色ボタンで手の追跡: MediaPipe(3D) / Vision(2D)。つまみは3Dの指先距離で判定
  • 手の骨格が白い球と水色の骨で出ます。指1本1本で押せます
